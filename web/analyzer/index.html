Cooperative Analytics ตัวอย่างข้อมูล: สหกรณ์การเกษตร (ครบถ้วน)

ระบบวิเคราะห์ข้อมูลสหกรณ์ / กลุ่มเกษตรกร อัตโนมัติ

วิเคราะห์หลัก 4M • อัตราส่วนทางการเงิน & CAMELS • ธุรกิจรายประเภท • สวัสดิการ • ปัญหาและแผน 3 ระยะ

1. นำเข้าข้อมูลสหกรณ์ / กลุ่มเกษตรกร

โยนไฟล์ (.json, .csv, .xlsx, .pdf, .txt) หรือวางข้อความรายงาน/งบการเงิน ระบบจะแยกข้อมูลและประมวลผลให้อัตโนมัติ

↑

ลากไฟล์มาวางที่นี่ หรือ คลิกเพื่อเลือกไฟล์

รองรับ Excel (.xlsx, .xls), CSV, JSON, PDF (สกัดข้อความอัตโนมัติ) และ Text (.txt)

ระบบจะสกัดตัวเลขและข้อความสำคัญตามโครงสร้าง 4M, ธุรกิจ และสวัสดิการให้ทันที
ตัวเลือกเสริม: เชื่อมต่อ Gemini API สำหรับสกัดข้อมูลจากเอกสารภาษาไทยที่ซับซ้อน (ไม่บังคับ — ระบบมีตัววิเคราะห์ในตัวอยู่แล้ว)

สถานะ: ใช้ระบบวิเคราะห์กฎเกณฑ์อัตโนมัติในเครื่อง (Offline Parser)

สถานะข้อมูลปัจจุบัน: กำลังแสดงข้อมูลตัวอย่างสหกรณ์การเกษตร (ครบทุกมิติ)
